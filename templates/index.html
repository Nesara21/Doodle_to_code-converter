How it actually works

Classical computer vision

Sketches are grayscaled, thresholded and passed through OpenCV contour detection. Shape heuristics — aspect ratio, vertex count, circularity — classify each contour, no learned model involved.

Keyword parsing

Prompts are scanned for a fixed vocabulary of UI terms. Matching rules decide which template blocks to combine and in what order — plain pattern matching, not language generation.

Template assembly

Detected components or matched blocks are stitched into a single HTML document from hand-written templates, then rendered live in the preview pane.
